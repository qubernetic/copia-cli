# Installation

Pick your platform and a method. Each link opens the steps for that method.

| Platform | Methods |
|---|---|
| Linux | [Homebrew](linux.md#homebrew), [Debian/Ubuntu (.deb)](linux.md#debianubuntu-deb), [Fedora/RHEL (COPR)](linux.md#fedorarhel-copr), [Snap](linux.md#snap), [AUR (Arch Linux)](linux.md#aur-arch-linux), [precompiled binaries](linux.md#precompiled-binaries) |
| macOS | [Homebrew](macos.md#homebrew), [precompiled binaries](macos.md#precompiled-binaries) |
| Windows | [WinGet](windows.md#winget), [precompiled binaries](windows.md#precompiled-binaries) |
| Any | [Build from source](source.md) |

Every release, with its packages, archives and checksums, is on the [releases page](https://github.com/qubernetic/copia-cli/releases).

After installing, check that the binary is on your `PATH`:

```bash
copia-cli --version
```

Next, [sign in](../getting-started/authentication.md).
